# Mohit Singh — Portfolio Website

A responsive personal portfolio for Mohit Singh, a BCA student at Galgotias University with a strong interest in web development.

## What's included

- `index.html` — page content and structure
- `styles.css` — layout, colors, responsive styles, and project preview artwork
- `script.js` — mobile navigation, active section highlighting, reveal effects, and project filters
- `assets/favicon.svg` — browser tab icon

## Run the website

This is a static website. No framework, package manager, or build step is required.

1. Download and extract the ZIP file.
2. Open the `mohit-portfolio` folder.
3. Double-click `index.html` to open it in your browser.

For local development, you can also use the Live Server extension in Visual Studio Code.

## Publish it online

You can deploy the folder using GitHub Pages, Netlify, or Vercel. For GitHub Pages, create a repository, upload all files while keeping `index.html` in the repository root, then enable Pages in the repository settings.

## Personalize the content

Open `index.html` and update any details as needed:

- Education details and location
- About section and current focus
- Project descriptions and repository URLs
